# 나의 중학교 3년 인포그래픽 웹앱

이 프로젝트는 별도의 서버나 빌드 과정 없이 GitHub Pages에서 실행되는 단일 HTML 웹앱입니다.

## GitHub Pages 배포하기

1. GitHub에서 새 저장소를 만듭니다.
2. 저장소 최상위에 `index.html`을 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 지정하고 **Save**를 누릅니다.
6. Pages 설정 화면에 표시되는 사이트 주소를 열어 앱을 확인합니다.

`index.html`은 외부 라이브러리나 별도의 이미지 파일 없이 동작합니다. 학생 데이터는 각 사용자의 브라우저에 저장됩니다.
